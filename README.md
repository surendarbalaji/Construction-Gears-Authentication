a neat little euclidian construction visualisation program

I had to pivot from the original idea of this project, which was to create a sort of authentication system with the euclidian constructions, however i was out of time before I could fully realise that. i've instead turned this into a sandbox visualisation tool to make rad looking constructions  

## features
* **gear placement** - place 'gears' (just points that the constructions start at, the whole gear aspect had more relevance in my original idea trust me)
* **colour themes** - there are, in fact, colour themes
* **geometric constructions** - type letters to trigger geometric constructions, i recommend a lot of gears for maximum effect

## controls
* Up arrow and Down arrow to change number of gears (get those numbers up)
* Number keys to select colour scheme
* Type letters on keyboard to construct

There are actually quite a few more indeed complicated constructions in this project however I didn't get a chance the implement them into the sandbox system i pulled together, but the files are still here, if you want to try them for some reason (just use the commands in each script to initialise, update and draw them)
